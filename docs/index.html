Encoding

TLS session · mode 13

Decode complete TLS 1.2 application records with exported session keys. Session data stays in this page and is cleared on reload. For AFL captures, first reassemble and remove the AFL framing. TLS handshakes are not supported.

Use the key and salt for the selected direction. The counter counts TLS records, including encrypted handshake records. Repeating a decode does not advance it. TLS session output supports JSON, YAML, Table, CSV, and Diagram.

Help

Accepts wired and wireless frames. If neither matches, tries application-layer data (starting with CI) or bare DIF/VIF records.

Enter the key supplied with the meter. Leave empty to inspect the telegram headers.

Keys stay in this browser tab and are excluded from share links and reports.
